영상 속 다섯 문제

본문 「확인 문제」

먼저 스스로 답해 본 뒤 「풀이 보기」를 눌러 맞춰 보세요. 헷갈리면 「다시 보기」의 움직이는 그림으로 돌아가면 됩니다.

  1. AI가 만든 HTML 파일을 휴대전화에서 볼 때, 화면과 브라우저는 각각 어느 편에 속할까?

    풀이 보기

    화면은 하드웨어, 브라우저는 소프트웨어입니다. 브라우저를 실행하는 운영체제와 그 아래 하드웨어가 함께 있어야 HTML이 보입니다.

    다시 보기: 움직이는 그림 1-A 두 세계의 경계

  2. 저장 공간은 넉넉한데 브라우저 탭을 많이 열면 느려진다. 어느 자원을 먼저 의심하겠는가?

    풀이 보기

    메모리(RAM)입니다. 탭마다 지금 쓰는 내용이 펼친 책상인 메모리에 올라옵니다. 서류 보관함(저장장치)이 넉넉해도 책상이 가득 차면 느려집니다. CPU 등 다른 원인도 있을 수 있으니 사용량을 직접 확인합니다.

    다시 보기: 움직이는 그림 1-B 컴퓨터 속 세 장소 — 「직접 해 보기」에서 탭을 여러 개 열어 보세요

  3. “앱이 설치는 됐는데 시작하지 않아요”에서 설치와 실행은 어떻게 다른가?

    풀이 보기

    설치는 파일과 설정을 저장장치에 준비하는 단계, 실행은 그 파일을 메모리에 올려 CPU가 일하게 하는 단계입니다. 이 문장은 준비는 끝났지만 실행에서 막힌 상황입니다. 설치 성공과 정상 실행은 다릅니다.

    다시 보기: 움직이는 그림 1-C 설치에서 실행까지

  4. AI가 “이 코드를 실행하려면 Python이 필요합니다”라고 했다. Python은 기기의 물리적 부품일까?

    풀이 보기

    아닙니다. Python은 Python 코드를 실행하기 위해 내 컴퓨터에 설치하는 소프트웨어(실행 환경)입니다. 부품을 사러 갈 일이 아니라 설치하면 됩니다.

    다시 보기: 움직이는 그림 1-A 두 세계의 경계

  5. 공공서비스 앱 README의 사전 요구사항 여섯 줄 가운데 하드웨어는 몇 개일까?

    풀이 보기

    하나도 없습니다. Node.js 18+와 Python 3.11+는 실행 환경(소프트웨어), Supabase · Upstash Redis · Kakao Developers 계정과 Seoul API 키는 인터넷 서비스의 계정과 열쇠입니다. 그래도 앱은 노트북의 CPU · 메모리 · 저장장치 위에서 돕니다.

    다시 보기: 강의 자료 3부 · 실제 저장소 읽기
